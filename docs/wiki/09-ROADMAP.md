# Roadmap (Planning only)

0. **Documentation/truth inventory:** requirements, decisions, status labels, implementation and deployment audit.
1. **Data reliability:** adapters, schema, freshness, timestamp/session normalization, outage behavior, quality flags.
2. **Multi-source comparison:** simultaneous sources where permitted; alignment, quality evaluation, disagreement and calibrated consensus.
3. **Evidence engine:** horizon relevance, dependence-aware evidence, conflict and HOLD logic.
4. **Forecasting:** baselines, statistical/regime models and optional ML only when justified; probabilistic calibration.
5. **Risk/scenarios:** calculations and guardrails; demo-only learning posture.
6. **API:** versioned endpoints and robust schemas/errors for forecasts, snapshot, quality, news/calendar, risk and model health.
7. **Mobile app:** market, forecast, source transparency, events, risk and model health; mobile-first.
8. **Integrations:** MT5, TradingView, cTrader after feasibility/licensing.
9. **Operations/release:** tests, secrets, security, monitoring, deployment verification, release gates.

Phases can change with user decisions and evidence; none is implied complete by being listed.
